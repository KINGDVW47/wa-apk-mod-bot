# BaliBuddy WA 🤖

Bot WhatsApp pou modifikasyon APK, deplwaye 24/7 sou Railway.

## Kijan li mache
1. Bot konekte ak WhatsApp pa pairing code (oswa QR).
2. Ou aktive bot sou yon grup (`/aktive`).
3. Ou voye yon `.apk` → bot dekonpile, chanje non, enjekte Toast, rekonstwi, siyen, epi voye APK mod la tounen.

## Kòmand nan chat
- `/help` — lis kòmand
- `/aktive` — aktive bot sou grup
- `/dezaktive` — dezaktive
- `/estati` — eta koneksyon
- `/ls` — lis gwoup aktif

## Dashboard
Paj web (pò 3000) pou wè koneksyon, lis gwoup, epi aktive/dezaktive gwoup yo.

## Deplwaye
- Push sou GitHub → Railway deplwaye otomatikman.
- Dossier `session/` konsève koneksyon WhatsApp ou.

## Sécurité / Kondisyon
Sèvi sèlman ak APK ou gen dwa modifye (pwopryetè ou).
